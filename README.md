# persian-banking-llm-chatbot
چت‌بات بانکی فارسی (Intent Detection + Slot Filling + Multi-turn) مبتنی بر LLM Prompting
# چت‌بات بانکی فارسی چندنوبته (مبتنی بر مدل زبانی)

چت‌باتی که یک مکالمه‌ی چندنوبته (multi-turn) با کاربر برقرار می‌کند تا عملیات بانکی موردنظرش را انجام دهد.

## تسک

1. **تشخیص قصد (Intent Detection):** از پیام کاربر تشخیص داده شود چه عملیاتی می‌خواهد (مثلاً انتقال وجه،
   استعلام موجودی، پرداخت قبض، درخواست وام و ...).
2. **تکمیل اسلات‌ها (Slot Filling):** اطلاعات لازم برای انجام آن عملیات (مبلغ، شماره حساب/کارت گیرنده، تاریخ
   و ...) به‌صورت چندنوبته از کاربر پرسیده و تکمیل شود.
3. **خروجی نهایی:** پس از تکمیل همه‌ی اطلاعات ضروری، یک شیء JSON شامل قصد و پارامترهای نهایی تولید شود:

```json
{
  "intent": "card2card",
  "parameters": {
    "transfer_amount": "200000",
    "receiver_card": "6037991234567890"
  }
}
```

هم تشخیص قصد و هم تکمیل اسلات‌ها (و همچنین نرمال‌سازی پاسخ‌های آزاد کاربر در طول مکالمه) با **prompting یک
مدل زبانی بزرگ (LLM)** — از طریق API تجاری (Claude یا GPT) — انجام می‌شود؛ نیازی به فاین‌تیون یا آموزش هیچ
مدلی نیست.

## ساختار پروژه

| فایل | وظیفه |
|---|---|
| `00_setup_and_data_prep.ipynb` | آماده‌سازی لیست intent ها، لیست اسلات‌ها، و نگاشت هر intent به اسلات‌های موردنیازش |
| `01_intent_detection.ipynb` | تشخیص قصد کاربر با LLM |
| `02_slot_filling.ipynb` | استخراج/نرمال‌سازی مقادیر اسلات از پیام کاربر با LLM |
| `03_multi_turn_chatbot.ipynb` | مدیریت کامل مکالمه‌ی چندنوبته (کلاس `MultiTurnChatBot`) و تولید خروجی JSON نهایی |
| `04_evaluation.ipynb` | ارزیابی کمّی (روی داده‌ی validation، در صورت وجود) و کیفی (سناریوهای شبیه‌سازی‌شده) |
| `chatbot_common.py` | ماژول مشترک: کلاینت LLM، پارس خروجی JSON مدل، توابع بارگذاری داده |
| `data/slots.txt` | لیست برچسب‌های اسلات پروژه |
| `data/*.json` | خروجی نوت‌بوک ۰۰ (خودکار ساخته می‌شود) |

## پیش‌نیازها

```bash
pip install -r requirements.txt
```

یک کلید API لازم دارید :

```bash
export ANTHROPIC_API_KEY="..."     # اگر LLM_PROVIDER="anthropic" 
# یا
export OPENAI_API_KEY="..."        # اگر LLM_PROVIDER="openai"
```


## ترتیب اجرا

نوت‌بوک‌ها را دقیقاً به همین ترتیب اجرا کنید — هرکدام فایل‌های موردنیاز نوت‌بوک بعدی را در `data/` می‌سازد:

```
00_setup_and_data_prep.ipynb
        ↓
01_intent_detection.ipynb
        ↓
02_slot_filling.ipynb
        ↓
03_multi_turn_chatbot.ipynb   ← اجرای واقعی چت‌بات (تعاملی)
        ↓
04_evaluation.ipynb           ← ارزیابی نهایی
```
